# L'atome, couche par couche

Tableau périodique interactif pour réviser la chimie (9e, IB, en français).

Touche un élément pour voir :

- la répartition de ses électrons sur les couches K, L, M… avec le modèle en couches ;
- son schéma de Lewis (style points ou tirets) ;
- ce que l'atome a tendance à faire (gagner, perdre ou partager des électrons).

Le mode révision cache les réponses pour s'entraîner.

## Utilisation

Ouvre `index.html` dans un navigateur, ou active GitHub Pages sur ce dépôt.
Aucune installation n'est nécessaire : tout tient dans un seul fichier.
